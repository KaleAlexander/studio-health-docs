# Instagram grid

Nine square posts, 1080×1080. Four of them also have a 4-second silent loop. The still and the first frame of the loop match, so the grid looks the same either way.

Files are in `posts/`. `grid-preview.png` is the profile, top to bottom.

## Posting order

Instagram puts the newest post at the top left. Post **09 first** and **01 last** if you want the preview.

09 → 08 → 07 → 06 → 05 → 04 → 03 → 02 → 01

If you already have posts, this block sits above them as its own three rows. A pinned post stays in front of that and will shift the checkerboard.

For a video, you can leave the cover as the first frame. It matches the still.
